1. Objective

To implement Stack and Queue using arrays and linked lists and to learn Git and GitHub version control.

2. Programming Language

C++

3. Programs

1. Stack using Array
2. Queue using Array
3. Stack using Linked List
4. Queue using Linked List

4. Stack Operations

- PUSH
- POP
- PEEK
- DISPLAY

5. Queue Operations

- ENQUEUE
- DEQUEUE
- DISPLAY

6. Software Requirements

- Visual Studio Code
- C++ compiler (GCC)
- Git
- GitHub

7. How to Compile

Example for Stack using Array:

g++ Stack_Array.cpp -o Stack_Array

Run on Windows:

.\Stack_Array.exe

The same procedure can be followed for the other three programs by changing the file name.

8. Conclusion

This activity demonstrates Stack and Queue implementations using arrays and linked lists. It also provides experience in Git version control and GitHub repository management.
